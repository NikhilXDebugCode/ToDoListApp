# ✅ To-Do List Application

A simple and efficient **To-Do List application** designed to help users organize tasks, manage daily activities, and improve productivity with a clean and user-friendly interface.

---

## 🧠 Problem Statement

Managing daily tasks without a proper system often leads to missed deadlines and poor productivity.  
This application provides a **simple task management solution** that allows users to add, track, and manage their tasks effectively.

---

## 🚀 Features

- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- ❌ Delete tasks  
- ✅ Mark tasks as completed  
- 🧹 Clear completed tasks  
- 📱 Clean and intuitive UI
